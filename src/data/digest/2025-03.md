March was a month of new plugins: four of them, each filling a gap in something Obsidian already does.

## New plugins

### `Advanced Debug Mode`

Debug plugins without the usual friction: switch Obsidian's debug mode on and off from settings, get error stack traces that follow a call through `setTimeout` and event listeners instead of stopping short, open DevTools right inside the mobile app, and turn plugins' debug messages on and off from the UI.

![DevTools inside the mobile app](https://raw.githubusercontent.com/mnaoumov/obsidian-advanced-debug-mode/1.0.0/images/devtools.jpg)

[Plugin](https://github.com/mnaoumov/obsidian-advanced-debug-mode) · [1.0.0](https://github.com/mnaoumov/obsidian-advanced-debug-mode/releases/tag/1.0.0)

### `Advanced Exclude`

Make excluded files actually go away. Obsidian's own Excluded files setting still shows them in the File explorer and the Backlinks pane; this plugin hides them from the whole app. Write the rules in `.gitignore` syntax, in settings or in an `.obsidianignore` file, and reuse your vault's `.gitignore` if it has one.

[Plugin](https://github.com/mnaoumov/obsidian-advanced-exclude) · [1.0.0](https://github.com/mnaoumov/obsidian-advanced-exclude/releases/tag/1.0.0)

### `Advanced Note Composer`

Merge and extract with Note composer without cleaning up afterwards. Relative Markdown links in the moved text are fixed instead of left broken, and a heading with characters a file name cannot hold can still be extracted, with its original title kept as an alias or a `title` property.

[Plugin](https://github.com/mnaoumov/obsidian-advanced-note-composer) · [1.0.0](https://github.com/mnaoumov/obsidian-advanced-note-composer/releases/tag/1.0.0)

### `Backlink Full Path`

See where each backlink lives. The Backlinks pane shows the note's folder path, not just its name, so two notes called `Index` in different folders no longer look the same. Version 1.1.0 lets you choose how many folders to show and whether to show the extension.

![Backlinks with their full paths](https://raw.githubusercontent.com/mnaoumov/obsidian-backlink-full-path/1.0.0/images/full-path.png)

[Plugin](https://github.com/mnaoumov/obsidian-backlink-full-path) · [1.0.0](https://github.com/mnaoumov/obsidian-backlink-full-path/releases/tag/1.0.0) · [1.1.0](https://github.com/mnaoumov/obsidian-backlink-full-path/releases/tag/1.1.0)
