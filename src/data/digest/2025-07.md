July was a small month: no new plugins, but three changes to plugins you may already use.

## New in existing plugins

### `CodeScript Toolkit`: scripts inside notes

Keep your scripts in ordinary notes, as `code-script` blocks, instead of separate `.js` files, and load them from other scripts with `require('./tools.md')`, or by name when one note holds several. Since 8.21.0 a note like that can also be run straight from the Invoke Scripts commands.

[8.18.0](https://github.com/mnaoumov/obsidian-codescript-toolkit/releases/tag/8.18.0) · [8.21.0](https://github.com/mnaoumov/obsidian-codescript-toolkit/releases/tag/8.21.0)

### `Frontmatter Markdown Links`: text and several links in one property

A property can now hold ordinary text with links in it, such as `"[[bar]] baz [[qux]]"`, and every link in it is clickable. Before, a property had to be a single link.

[2.4.0](https://github.com/mnaoumov/obsidian-frontmatter-markdown-links/releases/tag/2.4.0)

### `Custom Attachment Location`: slugified names

Attachment names and folders can be slugified (`baz qux quux` becomes `baz-qux-quux`), lower-cased or upper-cased, and a new token adds the file's size to the name.

[8.0.0](https://github.com/mnaoumov/obsidian-custom-attachment-location/blob/8.0.0/CHANGELOG.md) · [8.1.0](https://github.com/mnaoumov/obsidian-custom-attachment-location/blob/8.1.0/CHANGELOG.md)
