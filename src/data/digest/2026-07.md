July brought no new plugins, but four of the existing ones learned something worth knowing about.

## New in existing plugins

### `Advanced Note Composer`: merge, split and flatten whole folders

Reshape notes and folders in one step. Merge several notes selected in the File explorer, or everything in a folder, into a single note. Split a note's headings into a folder tree, one note per heading. Flatten a folder by moving its contents up one level. Move a selection into another note, and rename a heading so that the links to it follow.

[5.1.0](https://github.com/mnaoumov/obsidian-advanced-note-composer/releases/tag/5.1.0)

### `Custom Attachment Location`: keep web images, drop unused attachments

Collecting attachments can now download the web images a note embeds and save them in your vault, so the note no longer depends on someone else's site (opt in). A new command, also on the menu, sends the attachments a note no longer uses to the trash after you confirm.

[11.5.0](https://github.com/mnaoumov/obsidian-custom-attachment-location/releases/tag/11.5.0)

### `Nested Properties`: find notes by nested property

Search for a nested property right in Obsidian's own search, for example `[book.author: value]`. It combines with every other search term and works in embedded query blocks. Nested properties can now be renamed, too.

[1.4.0](https://github.com/mnaoumov/obsidian-nested-properties/releases/tag/1.4.0)

### `Embed HTML`: embeds that fit their content

An embedded HTML file can grow or shrink to fit what it shows, with no inner scrollbar and no empty space below it. Write `![[file.html|-]]`, or give it a fixed height instead.

[2.0.0](https://github.com/mnaoumov/obsidian-embed-html/releases/tag/2.0.0)
