March brought one new plugin for everyone and two new testing tools for people who write plugins.

## New plugins

### `Nested Properties`

See and edit nested properties: a property inside a property, or a list of objects, which Obsidian's Properties view cannot show. They appear as a collapsible tree, and you can add, cut, copy, paste and remove values at any depth.

![Nested properties as a collapsible tree](https://raw.githubusercontent.com/mnaoumov/obsidian-nested-properties/1.0.0/images/screenshot.png)

[Plugin](https://github.com/mnaoumov/obsidian-nested-properties) · [1.0.0](https://github.com/mnaoumov/obsidian-nested-properties/releases/tag/1.0.0)

## For plugin developers

- **`obsidian-integration-testing`**: run integration tests against a real, running Obsidian. The Vitest setup builds a temporary vault and installs your plugin into it, and `evalInObsidian()` runs test code inside Obsidian with `app` at hand. [Repo](https://github.com/mnaoumov/obsidian-integration-testing) · [1.0.0](https://github.com/mnaoumov/obsidian-integration-testing/releases/tag/1.0.0)
- **`obsidian-test-mocks`**: unit-test plugin code without Obsidian, using in-memory stand-ins for every class and function in `obsidian.d.ts`, wired in with one Vitest alias. [Repo](https://github.com/mnaoumov/obsidian-test-mocks) · [1.0.0](https://github.com/mnaoumov/obsidian-test-mocks/releases/tag/1.0.0)
