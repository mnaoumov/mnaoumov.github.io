April was a busy month for releases but a small one for news: two features worth knowing about, the rest upkeep.

## New in existing plugins

### `Advanced Note Composer`: split a note by headings

Split a long note into one note per heading in a single command: pick the level, H1 to H6, and every section at that level becomes its own note, named after its heading. No more running Extract this heading once for each section.

[1.4.0](https://github.com/mnaoumov/obsidian-advanced-note-composer/releases/tag/1.4.0)

### `Custom Attachment Location`: Excalidraw drawings as attachments

Excalidraw drawings embedded in a note (`.excalidraw.md` files) are now handled like images: they go into the note's attachment folder and move with the note. This works out of the box, and you can add other extensions in settings.

[7.4.0](https://github.com/mnaoumov/obsidian-custom-attachment-location/blob/7.4.0/CHANGELOG.md)
