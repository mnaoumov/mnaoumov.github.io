July was a big month for me: two new plugins, and an attachment plugin that I took over and started extending.

## New plugins

### `Better Markdown Links`

For people who prefer Markdown links to wikilinks. Obsidian now writes readable links such as `[Title](<folder with space/note.md>)` instead of `%20`-encoded ones, and starts relative paths with `./` so they resolve the same way in other editors. Commands convert the links in one note or the whole vault. Since 1.1.0 new links are converted as you type them, and since 2.0.0 links are updated when files are renamed or moved.

[Plugin](https://github.com/mnaoumov/obsidian-better-markdown-links) · [2.0.0](https://github.com/mnaoumov/obsidian-better-markdown-links/releases/tag/2.0.0)

### `Refresh Preview`

Re-render Reading view with a button or a command, so dynamic content such as a `dataviewjs` block updates without reopening the note. The plugin has since been renamed `Refresh Any View`.

![The Refresh Preview button re-renders the note](https://raw.githubusercontent.com/mnaoumov/obsidian-refresh-any-view/1.0.0/images/demo.gif)

[Plugin](https://github.com/mnaoumov/obsidian-refresh-any-view) · [1.0.0](https://github.com/mnaoumov/obsidian-refresh-any-view/releases/tag/1.0.0)

### `Custom Attachment Location`: now maintained by me

Choose where attachments go and how pasted files are named, using tokens such as the note's name and the date. The plugin was started by another author in 2021. In its first week under new maintenance it learned to rename dropped files as well as pasted ones, ask you for a name with `${prompt}`, use the note's folder name and path, work with canvases, and move a note's attachment folder when the note is moved, not only renamed.

[Plugin](https://github.com/mnaoumov/obsidian-custom-attachment-location) · [3.6.0](https://github.com/mnaoumov/obsidian-custom-attachment-location/blob/3.6.0/CHANGELOG.md)
