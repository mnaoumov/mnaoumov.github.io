October was a big month: three new plugins, a handful of features in the ones you may already use, and a fresh set of tools for people who write plugins themselves.

## New plugins

### `Explorer Multi-Select`

Select many files and folders in Obsidian's own File explorer and act on them all at once: tick boxes on a phone or tablet, the keyboard keys desktop was missing, and commands that select by extension, glob or property. Delete the lot with one confirmation. Version 1.1.0 adds Shift+Space and a Clear selection button.

![Selection mode: tick rows, then act on them all](https://raw.githubusercontent.com/mnaoumov/obsidian-explorer-multi-select/1.1.0/images/screenshots/screenshot-desktop-1.png)

[Plugin](https://github.com/mnaoumov/obsidian-explorer-multi-select) · [1.0.0](https://github.com/mnaoumov/obsidian-explorer-multi-select/releases/tag/1.0.0) · [1.1.0](https://github.com/mnaoumov/obsidian-explorer-multi-select/releases/tag/1.1.0)

### `Labelled Links`

Say what a link means. Links you already write as `child:: [[Bob]]`, or as a `child` property, show their relation as a badge on the link, and Bob's note reads the same link as `parent`. A pane lists every relation of a note, both ways. Nothing is written into your notes. Version 1.1.0 adds hidden labels, written as `[[Bob]]%%:child%%`.

![Alice links Bob as child, so Bob reads it as parent](https://raw.githubusercontent.com/mnaoumov/obsidian-labelled-links/1.1.0/images/screenshots/screenshot-desktop-1.png)

[Plugin](https://github.com/mnaoumov/obsidian-labelled-links) · [1.0.0](https://github.com/mnaoumov/obsidian-labelled-links/releases/tag/1.0.0) · [1.1.0](https://github.com/mnaoumov/obsidian-labelled-links/releases/tag/1.1.0)

### `Sibling Notes`

Read a folder of notes in order (chapters, lessons, days of a trip) without going back to the File explorer for every step. Previous and next bars sit above and below the note, and a folder map shows where you are. Version 1.1.0 moves to the next or previous note when you scroll past the edge.

![Step through the folder in File explorer order](https://raw.githubusercontent.com/mnaoumov/obsidian-sibling-notes/1.1.1/images/screenshots/screenshot-desktop-1.png)

## New in existing plugins

### `Advanced Exclude`: switchable profiles

Keep several named sets of hidden files, say "Work" and "Focus", and switch between them from the status bar. Each device picks its own active set, and one set can build on another, or on the vault's `.gitignore`, through `@import`.

[4.2.0](https://github.com/mnaoumov/obsidian-advanced-exclude/releases/tag/4.2.0)

### `Advanced Note Composer`: sort sections

Sort a note's sections at one heading level alphabetically, by when each was created or last edited, or in reverse, instead of dragging them one by one. Sorting by time uses the heading timestamps from `Advanced Metadata Cache`.

[5.17.0](https://github.com/mnaoumov/obsidian-advanced-note-composer/releases/tag/5.17.0) · [5.18.0](https://github.com/mnaoumov/obsidian-advanced-note-composer/releases/tag/5.18.0)

### `Custom Attachment Location`: merge duplicates, name by content

Collecting attachments can now merge byte-identical files into one (opt in), and the new `{{attachmentFileHash}}` token names an attachment by a hash of its content, so the same image pasted twice is easy to spot.

[15.1.0](https://github.com/mnaoumov/obsidian-custom-attachment-location/releases/tag/15.1.0) · [17.0.0](https://github.com/mnaoumov/obsidian-custom-attachment-location/releases/tag/17.0.0)

### `Advanced Metadata Cache`: faster Unlinked mentions

The Backlinks pane's Unlinked mentions section now fills from a saved index instead of reading every note, so it stays quick in a large vault and lists exactly what it listed before.

[2.3.0](https://github.com/mnaoumov/obsidian-advanced-metadata-cache/releases/tag/2.3.0)

### `Advanced Debug Mode`: debug messages by checkbox

Turn any plugin's debug messages on or off by ticking it in a list, or with a command, instead of typing the `window.DEBUG.enable(...)` line a README tells you to paste into the console.

[1.13.0](https://github.com/mnaoumov/obsidian-advanced-debug-mode/releases/tag/1.13.0) · [1.14.0](https://github.com/mnaoumov/obsidian-advanced-debug-mode/releases/tag/1.14.0)

### Undo a whole bulk run, and report a bug from inside Obsidian

Bulk commands in `Consistent Attachments and Links` and `Custom Attachment Location` can now save each run as its own git commit (an opt-in setting, on desktop, for a vault kept in git), and an undo command lists the runs and reverts the one you pick. The same releases, and `Advanced Debug Mode`, add a **Report a bug** command that opens the plugin's issue form with your Obsidian, installer and plugin versions already filled in.

[Consistent Attachments and Links 5.3.0](https://github.com/dy-sh/obsidian-consistent-attachments-and-links/releases/tag/5.3.0) · [Custom Attachment Location 17.1.0](https://github.com/mnaoumov/obsidian-custom-attachment-location/releases/tag/17.1.0) · [Advanced Debug Mode 1.15.0](https://github.com/mnaoumov/obsidian-advanced-debug-mode/releases/tag/1.15.0)

## For plugin developers

- **`create-obsidian-plugin`**: start a new plugin, or bring an existing one up to date, from modern templates with one `npm create @mnaoumov/obsidian-plugin` wizard, which can also install dependencies, run `git init` and create the GitHub repo. [Repo](https://github.com/mnaoumov/create-obsidian-plugin) · [1.0.0](https://github.com/mnaoumov/create-obsidian-plugin/releases/tag/1.0.0)
- **`obsidian-dev-toolkit`**: one dev dependency to build, lint, test and release a plugin. Since 3.0.0 it builds with esbuild, vite, rollup, webpack or parcel, supports React, Svelte, Vue and Tailwind, and ships ready-made CI and release workflows. [Repo](https://github.com/mnaoumov/obsidian-dev-toolkit) · [1.1.0](https://github.com/mnaoumov/obsidian-dev-toolkit/releases/tag/1.1.0) · [3.0.0](https://github.com/mnaoumov/obsidian-dev-toolkit/releases/tag/3.0.0)
- **`obsidian-lib`**: the runtime library for plugins: base classes, settings tabs, modals, and vault, metadata-cache and link helpers. Together with the toolkit it replaces the retired `obsidian-dev-utils`. [Repo](https://github.com/mnaoumov/obsidian-lib) · [1.0.1](https://github.com/mnaoumov/obsidian-lib/releases/tag/1.0.1)
- **`obsidian-dataview-types`**: TypeScript types for calling Dataview that compile in your project, with working `getAPI` and `isPluginEnabled`. [Repo](https://github.com/mnaoumov/obsidian-dataview-types) · [1.0.0](https://github.com/mnaoumov/obsidian-dataview-types/releases/tag/1.0.0)
- **`More Events`**: add items to dozens of context menus Obsidian's API does not expose (canvas, bookmarks, PDF, Bases, callouts, table cells, the ribbon, the File explorer root) by subscribing to a named, typed event instead of patching internals. [1.2.0](https://github.com/mnaoumov/obsidian-more-events/releases/tag/1.2.0) · [1.3.0](https://github.com/mnaoumov/obsidian-more-events/releases/tag/1.3.0)
