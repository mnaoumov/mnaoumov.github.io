January brought one new plugin, small but useful if you script your vault.

## New plugins

### `Fix Require Modules`

Scripts you run inside Obsidian, in Templater, `dataviewjs` or the developer console, can now `require("obsidian")` and the CodeMirror modules, which otherwise fail with "Cannot find module". Desktop only. The plugin has since grown into `CodeScript Toolkit`.
