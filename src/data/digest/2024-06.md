June had one release worth your time, and it is a big one for anyone who writes scripts for their vault.

## New in existing plugins

### `Fix Require Modules`: scripts as commands and buttons

Your own JavaScript or TypeScript scripts become part of Obsidian. Every script in a folder you choose shows up in the Command palette, so it can have a hotkey. One script can run every time Obsidian starts. A `code-button` block puts a button in a note that runs code when you click it. Scripts can also load other scripts by relative path, ES modules and TypeScript files. 3.0.0 shipped broken, and 3.1.0 fixed it the same day. The plugin has since been renamed `CodeScript Toolkit`.
