December was a busy month: three new plugins, two features in existing ones, and a quick way to try out plugin code without building a plugin.

## New plugins

### `External Rename Handler`

Rename or move files outside Obsidian, in your file manager, a script or git, while Obsidian is open, and Obsidian treats it as a rename instead of a deleted file plus a new one, so links to the file keep working. Version 1.1.0 adds a setting to choose whether links are updated. Desktop only.

[Plugin](https://github.com/mnaoumov/obsidian-external-rename-handler) · [1.0.0](https://github.com/mnaoumov/obsidian-external-rename-handler/releases/tag/1.0.0) · [1.1.0](https://github.com/mnaoumov/obsidian-external-rename-handler/releases/tag/1.1.0)

### `Frontmatter Markdown Links`

Write Markdown links in properties, such as `[Note](Note.md)` or `[Site](https://example.com)`, and they work as links and show up in the Backlinks pane. Obsidian itself only understands wikilinks and bare URLs there. Version 1.3.0 handles lists of links, and 1.4.0 makes them clickable in Source mode too.

[Plugin](https://github.com/mnaoumov/obsidian-frontmatter-markdown-links) · [1.0.0](https://github.com/mnaoumov/obsidian-frontmatter-markdown-links/releases/tag/1.0.0) · [1.3.0](https://github.com/mnaoumov/obsidian-frontmatter-markdown-links/releases/tag/1.3.0) · [1.4.0](https://github.com/mnaoumov/obsidian-frontmatter-markdown-links/releases/tag/1.4.0)

### `Insert Multiple Attachments`

Pick several files in one file dialog and insert them all into the note at once, instead of running Insert attachment once for every file. Since 1.1.0 it is a command of its own.

[Plugin](https://github.com/mnaoumov/obsidian-insert-multiple-attachments) · [1.0.0](https://github.com/mnaoumov/obsidian-insert-multiple-attachments/releases/tag/1.0.0) · [1.1.0](https://github.com/mnaoumov/obsidian-insert-multiple-attachments/releases/tag/1.1.0)

## New in existing plugins

### `Custom Attachment Location`: name attachments by property or date

Attachment folders and file names can now use a note's property (`${frontmatter:key}`), the note's creation or modification date, random characters or a UUID. You can also define your own tokens as small JavaScript functions.

[5.0.0](https://github.com/mnaoumov/obsidian-custom-attachment-location/blob/5.0.0/CHANGELOG.md)

### `Backlink Cache`: canvas backlinks

The Backlinks pane of a note now lists the canvases that link to it, which Obsidian did not do on its own.

[2.0.0](https://github.com/mnaoumov/obsidian-backlink-cache/releases/tag/2.0.0) · [2.1.0](https://github.com/mnaoumov/obsidian-backlink-cache/releases/tag/2.1.0)

## For plugin developers

- **`Fix Require Modules`** (now `CodeScript Toolkit`): prototype a plugin from inside Obsidian. A code button defines a plugin class and loads it with `registerTempPlugin()`, and a command unloads it again. This release also brings a first, limited mobile version. [7.0.0](https://github.com/mnaoumov/obsidian-codescript-toolkit/releases/tag/7.0.0)
