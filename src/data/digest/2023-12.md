December brought two small new plugins, both fixing things in the File explorer.

## New plugins

### `File Explorer Reload`

When files you copied, moved or deleted outside Obsidian do not show up correctly in the File explorer, reload it, or just one folder, instead of restarting Obsidian, which takes a while in a large vault. Version 1.1.0 adds Reload Folder items to the folder menu. Desktop only, since 1.2.0.

[Plugin](https://github.com/mnaoumov/obsidian-file-explorer-reload) · [1.1.0](https://github.com/mnaoumov/obsidian-file-explorer-reload/releases/tag/1.1.0)

### `Root Folder Context Menu`

Right-click the vault name at the top of the File explorer and get the same menu as any other folder, so New note, New folder and the rest work at the vault root too.

[Plugin](https://github.com/mnaoumov/obsidian-root-folder-context-menu) · [1.0.0](https://github.com/mnaoumov/obsidian-root-folder-context-menu/releases/tag/1.0.0)
