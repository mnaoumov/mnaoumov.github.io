October was a small month: two new plugins, each fixing one everyday annoyance in the editor.

## New plugins

### `Edit Link Alias`

Change what a link displays without picking apart `[[Note|text]]` by hand. Put the cursor on a link and choose `Edit link alias` from the editor's right-click menu, or `Edit Link Alias: Edit` from the Command palette; type the new text and the link is rewritten, staying a wikilink or a markdown link as it was.

![Edit link alias prompt](https://raw.githubusercontent.com/mnaoumov/obsidian-edit-link-alias/1.0.0/images/prompt.png)

[Plugin](https://github.com/mnaoumov/obsidian-edit-link-alias) · [1.0.0](https://github.com/mnaoumov/obsidian-edit-link-alias/releases/tag/1.0.0)

### `Fix Tab Size`

With `Indent using tabs` off, Obsidian inserts 4 spaces on Tab whatever your `Indent visual width` says. This plugin makes Tab insert the width you set.

[Plugin](https://github.com/mnaoumov/obsidian-fix-tab-size) · [1.0.0](https://github.com/mnaoumov/obsidian-fix-tab-size/releases/tag/1.0.0)
