August was mostly groundwork: three new plugins and one feature worth knowing about in an existing one.

## New plugins

### `Advanced Rename and Delete Handler`

Rename or move a note and its links follow, and the attachments it owns travel with it, folder and all. Deleting a note can also clean up the attachments only that note used and the folder it leaves empty (off by default), and an attachment two notes share is never deleted with one of them. Several plugins used to carry their own copy of this, and two copies acting on one rename could break links; this plugin now does it once for the whole vault.

![Rename a note and every link to it follows](https://raw.githubusercontent.com/mnaoumov/obsidian-advanced-rename-and-delete-handler/1.0.0/images/screenshots/screenshot-desktop-2.png)

### `App Update Notifier`

Turn off Obsidian's automatic updates and still hear about new versions. It watches the app, the insider (Catalyst) build and the installer, shows what is behind in the status bar, and announces each new version once, with a link to its changelog. It also warns when your installer's Electron is too old for some Obsidian features. It never installs anything.

![Every stream it watches, with a changelog link on each](https://raw.githubusercontent.com/mnaoumov/obsidian-app-update-notifier/1.0.0/images/screenshots/screenshot-desktop-2.png)

[Plugin](https://github.com/mnaoumov/obsidian-app-update-notifier) · [1.0.0](https://github.com/mnaoumov/obsidian-app-update-notifier/releases/tag/1.0.0)

### `Link Picker`

Insert a link by browsing folders instead of guessing names: Enter on a folder goes in, `..` comes back out, and an exact name always ranks first. A picker rooted in one folder, say `People`, can become its own command, and templates and scripts can call the picker to get a link back.

![Navigate folders instead of guessing names](https://raw.githubusercontent.com/mnaoumov/obsidian-link-picker/1.0.0/images/screenshots/screenshot-desktop-1.png)

[Plugin](https://github.com/mnaoumov/obsidian-link-picker) · [1.0.0](https://github.com/mnaoumov/obsidian-link-picker/releases/tag/1.0.0)

## New in existing plugins

### `Custom Attachment Location`: clean up unused attachments vault-wide

Delete every attachment that no note uses any more, across the whole vault, after one confirmation, instead of going note by note. New commands also jump from a note to the folder its attachments go to, and from an attachment back to the note that owns it.

[11.9.0](https://github.com/mnaoumov/obsidian-custom-attachment-location/releases/tag/11.9.0) · [11.11.0](https://github.com/mnaoumov/obsidian-custom-attachment-location/releases/tag/11.11.0)
