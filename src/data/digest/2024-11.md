November was a quiet month, with one feature worth your time.

## New in existing plugins

### `Refresh Preview`: automatic refresh

Reading view can now refresh itself, whenever the file changes or every so many seconds, so dynamic content such as a `dataviewjs` block stays current without pressing the refresh button or reopening the note. The plugin has since been renamed `Refresh Any View`.

[2.0.0](https://github.com/mnaoumov/obsidian-refresh-any-view/releases/tag/2.0.0)
