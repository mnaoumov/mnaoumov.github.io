September was a busy month for releases but a quiet one for news: one new plugin and two features worth knowing about.

## New plugins

### `Embed HTML`

Embed an HTML file in a note with `![[page.html]]`, the way you would an image or a PDF. Version 1.1.0 lets you set the size (`![[page.html|400x300]]`), scroll to an element by its id, or show only that element (`![[page.html#intro&mode=extract]]`), and makes the embeds work inside Excalidraw drawings.

[Plugin](https://github.com/mnaoumov/obsidian-embed-html) · [1.1.0](https://github.com/mnaoumov/obsidian-embed-html/releases/tag/1.1.0)

## New in existing plugins

### `Advanced Note Composer`: split a note at the cursor

Put the cursor where a note should break and run `Extract before cursor...` or `Extract after cursor...`: that part moves to a new note and a link to it stays behind. And when you merge one note into another, sections under the same heading can now be combined instead of repeated.

[2.1.0](https://github.com/mnaoumov/obsidian-advanced-note-composer/releases/tag/2.1.0)

### `Custom Attachment Location`: default size for pasted images

Set a default size, such as `600px` or `50%`, and every image you paste comes in at that size, so you no longer resize each one by hand. Leave it blank to keep the original size.

[9.17.0](https://github.com/mnaoumov/obsidian-custom-attachment-location/blob/9.17.0/CHANGELOG.md)
