January was a small month: one new plugin, and one existing plugin that grew a new name and a lot more reach.

## New plugins

### `New Note Fixer`

Click a link to a note that does not exist yet, such as `[[folder/note]]` or `[[../folder/note]]`, and the note is created where your "Default location for new notes" setting says. Without it, Obsidian ignores that setting for such links, makes a stray folder at the vault root, or writes a file outside the vault that it then cannot open.

[Plugin](https://github.com/mnaoumov/obsidian-new-note-fixer) · [1.0.0](https://github.com/mnaoumov/obsidian-new-note-fixer/releases/tag/1.0.0)

## New in existing plugins

### `CodeScript Toolkit`: scripts and code buttons on mobile

The plugin formerly called `Fix Require Modules` now runs your vault scripts and `code-button` blocks on mobile as well as desktop. Code buttons also show console output right under the button, can render Markdown there, and on desktop can print the last value or run on their own when the note opens.
